How to type special characters

⊞ Windows Alt codes

For a listed legacy code, enable Num Lock if needed, hold Alt, type the digits on the numeric keypad (including the leading zero), then release Alt. Results depend on app and keyboard configuration.

⌘ Mac

Use the Character Viewer with Control + Command + Space (or Fn + E on supported Macs), search for the symbol, then insert it. Only use an Option shortcut when one is specifically documented.

▣ Microsoft Word

For many symbols, type the Unicode hexadecimal value without U+, then press Alt + X in Word. If conversion is ambiguous, select the code before pressing Alt + X.

Frequently asked questions

Does every symbol have an Alt code?

No. Traditional Windows Alt codes are limited. This tool displays a legacy Alt code only for entries where one is provided; Unicode is available for all listed characters.

Can I use this tool on a phone?

Yes. Search a symbol and tap Copy. Physical keyboard Alt codes generally do not work on phone keyboards.

Why does a symbol look different on another device?

Fonts and operating systems render characters differently. Some devices may not support certain symbols.
